# Broomly

Broomly is a Windows 10/11 disk cleaner: it finds caches, old files and folders, unused programs and games, explains what each one is, and deletes only what you check.

**Download:** open [Releases](https://github.com/alvenseenaren/Broomly-releases/releases/latest) and get `Broomly.exe` (run it, no install needed) or `Broomly.zip` (the exe plus instructions in 4 languages).

`SHA256SUMS.txt` holds the checksums. Broomly checks this page on start and offers to update when a newer version is out.

This repository only holds the downloads.
